# Recursos del lanzador

Los PNG y el ICO se distribuyen con la aplicación y se cargan desde esta carpeta,
relativa al archivo del lanzador. No necesitan internet, Pillow ni fuentes descargadas.

Logo CEMEX: https://www.freelogovectors.net/cemex-logo/
Archivo original facilitado por el usuario: https://www.freelogovectors.net/wp-content/uploads/2019/02/cemexlogo.png
El icono de cuadrícula se creó para este lanzador.

Para compartir: copiar el proyecto completo, incluida esta carpeta. En cada equipo,
ejecutar `Crear acceso directo.cmd` o `Generador de Matrices.cmd`. El acceso se crea
en el escritorio real de ese usuario, incluido un escritorio redirigido por OneDrive.
No distribuir el archivo .lnk de otra computadora. Si se mueve el proyecto, recrear
el acceso directo. El icono personalizado es del acceso y de la ventana; Windows
puede mantener su icono de Python para el archivo .pyw por la asociación del sistema.

Requiere Windows con Tk y las dependencias del proyecto. No se garantiza que las
políticas corporativas permitan ejecutar scripts o crear accesos en todos los equipos.
